# fde-lab-demo-acme

Repository di prova ("cliente" Acme, Portale ordini) per **fde-lab**. Non è un prodotto reale.

- Gli agenti AI di fde-lab lavorano su branch `suite/<projectId>` e aprono una PR verso `main`.
- Le skill dei worker sono in `.claude/skills/`.
- **Non inserire dati reali di clienti** (né segreti o token): tutto qui deve essere fittizio.

## Comandi

```bash
pnpm install
pnpm lint
pnpm test
pnpm build
```
